## Description

Model predicting likelihood of recycling bin contamination at route and neighbourhood level.

## Business Purpose

Target education and enforcement actions to improve recycling quality and reduce processing costs.

## Data Sources

* Recycling collection outcomes
* Materials Recovery Facility contamination audits
* Property type and participation data

## Key Outputs

* Route Contamination Risk Score
* Neighbourhood Risk Tier
* Predicted Contamination Hotspots
* Suggested Intervention Type

## Questions This Answers

* Which routes should receive targeted engagement?
* Where are contamination risks likely to increase?
* Which interventions are likely to have greatest impact?
