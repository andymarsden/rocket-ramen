## Description

Operational dashboard for refuse and street-cleansing fleet availability, utilisation and downtime.

## Business Purpose

Improve fleet reliability and optimise vehicle deployment across frontline services.

## Data Sources

* Vehicle Telematics
* Workshop Maintenance System
* Driver Rostering System

## Key Measures

* Fleet Availability (%)
* Vehicle Utilisation (%)
* Unplanned Downtime Hours
* Mean Time to Repair (Hours)
* Fuel Consumption (Litres)

## Questions This Answers

* Which vehicles have recurring faults?
* Are there enough available vehicles for scheduled rounds?
* How does downtime affect missed collections?
