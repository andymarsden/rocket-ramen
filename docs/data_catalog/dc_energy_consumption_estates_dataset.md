## Description

Metered electricity and gas consumption dataset for council offices, depots, schools and community buildings.

## Business Purpose

Support carbon accounting, cost control and estate decarbonisation planning.

## Data Sources

* Automated meter reads
* Utility invoices
* Building asset register

## Key Fields

* Site ID
* Meter Type
* Reporting Month
* Consumption (kWh)
* Cost (GBP)
* Estimated Emissions (tCO2e)

## Questions This Answers

* Which buildings are highest energy users?
* Where is consumption diverging from seasonal norms?
* Which retrofit projects delivered measurable savings?
