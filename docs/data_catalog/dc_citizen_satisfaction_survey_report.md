## Description

Quarterly report summarising resident satisfaction with key council services and trust indicators.

## Business Purpose

Inform service improvement priorities and monitor public confidence in council delivery.

## Data Sources

* Resident Survey Platform
* Demographic Weighting Reference Data
* Service Performance Dashboards

## Key Measures

* Overall Satisfaction with Council Services (%)
* Service-Specific Satisfaction Scores
* Net Trust Score
* Perceived Value for Money (%)
* Top Improvement Priorities

## Questions This Answers

* Which services are viewed most and least positively?
* How is trust changing over time?
* Which resident groups report lowest satisfaction?
