## Description

Core operational dataset of household, recycling and garden waste collection events at property and route level.

## Business Purpose

Provide detailed collection records for performance monitoring, service planning and statutory reporting.

## Data Sources

* In-Cab Collection System
* Waste Management System
* GIS Property Database

## Key Fields

* Collection Date
* Property UPRN
* Collection Round
* Waste Stream
* Collection Outcome
* Crew ID

## Questions This Answers

* Which properties were collected on a given date?
* Which rounds have the highest failure rates?
* How do completion rates vary by waste stream?
