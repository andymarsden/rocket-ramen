## Description

## Business Purpose

Assess service deployment and cleanliness outcomes to support local environmental standards.

* Supervisor Inspection Logs

## Key Measures

* Streets Swept
* Litter Bins Emptied
* Cleansing Requests Closed Within 48 Hours (%)
* Repeat Hotspot Incidents
* NI 195 Equivalent Cleanliness Score

## Questions This Answers

* Which locations need increased cleansing frequency?
* Are response times meeting local standards?
* How are cleanliness scores changing over time?
