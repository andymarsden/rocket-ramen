## Description

## Business Purpose

Support financial resilience and fair, timely collection of local taxation.

## Data Sources

* Payments Platform

## Key Measures

* In-Year Collection Rate (%)
* Arrears Balance
* Direct Debit Uptake (%)
* Recovery Action Conversion Rate (%)
* Claimant Exemption and Discount Volumes

## Questions This Answers

* Are collection levels tracking against target?
* Which wards show rising arrears risk?
* Which recovery stages create delay?
