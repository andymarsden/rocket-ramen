## Description

Forecasting model estimating short and medium-term demand for adult social care assessments and packages.

## Business Purpose

Improve workforce and budget planning by anticipating service demand pressures.

## Data Sources

* ASC Case Management System
* Population Projections
* Hospital Discharge Data
* Deprivation and Health Indicator Datasets

## Key Outputs

* Forecast Assessments per Month
* Forecast Package Starts
* Predicted Waitlist Size
* Demand by Support Need Category

## Questions This Answers

* How much assessment demand is expected next quarter?
* Which support categories are growing fastest?
* What staffing pressure is likely by locality?
