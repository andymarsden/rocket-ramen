## Description

Dataset of resident-reported missed bin incidents, request statuses and resolution outcomes.

## Business Purpose

Track customer impact from missed collections and monitor service recovery timeliness.

## Questions This Answers

* How many missed bins are being reported each week?
* Which areas generate repeat missed-bin cases?
* Are requests resolved within target timescales?
