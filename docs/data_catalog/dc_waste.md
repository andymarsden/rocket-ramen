## Description

Operational dashboard used by Waste Services managers to monitor household waste, recycling and garden waste collection performance across the borough.

The dashboard supports operational management, service planning and performance reporting by providing visibility of collection activity, missed collections and route performance.

## Business Purpose

Provide a single source of truth for waste collection performance and identify areas requiring operational intervention.

## Data Sources

* In-Cab Collection System
* Waste Management System
* Customer Contact Centre
* GIS Property Database

## Key Measures

### Collection Activity

* Total Bin Collections
* Household Collections Completed
* Recycling Collections Completed
* Garden Waste Collections Completed

### Service Performance

* Collection Success Rate (%)
* Missed Collections
* Missed Collections per 1,000 Properties
* Repeat Missed Collections
* Collections Completed On Schedule (%)

### Customer Impact

* Missed Collection Complaints
* Service Requests Raised
* Average Resolution Time (Days)

### Operational Efficiency

* Collections per Crew
* Collections per Route
* Average Route Completion Time
* Vehicle Utilisation

## Questions This Answers

* How many bin collections were completed this week?
* How many collections were missed?
* Which areas have the highest number of missed collections?
* Are collection success rates improving?
* Which routes generate the most complaints?
* How quickly are missed collections resolved?
* How does recycling collection performance compare with refuse collection performance?
