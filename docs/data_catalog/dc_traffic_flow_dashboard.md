## Description

Dashboard of traffic volumes, journey times and congestion hotspots on key local corridors.

## Business Purpose

Support network management decisions and evaluate transport policy interventions.

## Data Sources

* Loop and camera traffic counters
* Journey time probe data
* Roadworks and incident logs

## Key Measures

* Average Daily Traffic by Corridor
* Peak-Hour Journey Time Index
* Corridor Reliability Score
* Average Traffic Speed (mph)
* Congestion Hotspot Count

## Questions This Answers

* Which corridors have worsening congestion?
* How do roadworks impact journey reliability?
* Where should network interventions be prioritised?
